两个跑在你电脑上的 Windows 小工具

一个帮项目经理把项目文件管得住：给本地文件打上你自己的一套标签， 再到 Office 和 PDF 的正文里搜关键词。另一个替人把下载完的文件收进归档目录。 两个都是本地软件，不用注册，不联网，也不上传任何数据。

产品 01

PMDir — 本地文件标签与全文检索

把本地项目文件夹登记进来，在文件树上打一套只属于你的标签， 把标签条件组合成查询，再直接搜 Office 与 PDF 的正文。 全程离线：不开网络、不收集、不上传。

  • 不联网、不收集、不上传。没有账号，没有遥测，界面不加载任何远程字体或图片。
  • 标签可以分分类。每个分类有颜色、有排序，可以带值，分类之间还能互斥。
  • 查询用 AND / OR / NOT 组合，改一个条件，命中数当场就变。
  • 正文能搜。docx / xlsx / pptx / PDF / md / txt / csv 都行； .doc / .xls / .ppt 这几种老格式也能读，不需要装 Office。
  • 排序跟 Windows 资源管理器一致：拼音序、自然数字序。
  • 标签跟着文件走。复制、粘贴之后，标签还在。
  • 能导出 CSV，导出时做了表格公式注入的防护。
  • zip 与 7z 的读写是内置的（压成 7z 需要系统里装有 7z.exe）。
  • 删除只进回收站，没有永久删除这一说。
  • 库文件和索引坏了能自己修。
  • 三种界面语言（简中、繁中、英文）、三套配色（跟随系统 / 浅色 / 深色）。
  • 「折叠视图」能把整个窗口收成一条横条。

「索引 N%」那一栏说实话：它说的是有多少文件已经抽过正文，不是索引层的健康度； 索引层这次没能打开时，它显示的是「索引 —」。

产品 02

Download2 — 下载完就自己归档

一条 236 × 40 的小条子盯着你的「下载」文件夹。文件下完了，它就把这个文件 搬进你指定的归档目录，可以按下载日期再分子目录。 它不是下载管理器，也不加速下载。

  • 判断「下载完了」有七条：静置窗口（默认 900 毫秒，可调 200–5000 毫秒）、 连续两次采样的文件大小与修改时间不变、没有临时文件还指着它、锁探测、 临时文件名单（.crdownload .part .download .partial .tmp .idmdownload .__partialdownload、~$*）、大小不为 0、 且不在启动时的存量名单里。
  • 没下完的文件绝不搬。
  • 同名不覆盖。自动加 (1)、(2)，最多到 999 —— 因为 Windows 重命名会悄悄吃掉已经存在的目标。
  • 同盘移动是两次重命名，一个字节都不拷。 跨盘才退回复制路径，并且要在删源之前做一次字节数核对。
  • 崩了能续上。追加写的 pending.jsonl 账本配一张纯函数重放表， 下次启动把搬了一半的文件接回去。
  • 有些地方它不搬。「下载」文件夹里面、盘根目录、 \Windows 与 Program Files，都拒绝。
  • 设置坏了会隔离，不会悄悄重置。
  • 只有一个窗口。无边框、置顶、透明、不进任务栏； 每项设置自动保存，没有「保存」按钮。
  • 中英双语，浅色深色两套。

它不做什么：它没有下载引擎，不加速、不支持 BT 或 ED2K，没有断点续传， 没有浏览器插件，没有插件系统，没有系统托盘图标，也没有安装程序和自动更新—— 发布的是解压即用的便携版。
