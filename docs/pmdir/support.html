常见问题

我的数据到底放在哪里？

全部在「设置 → 数据位置」所示的目录下面：data\ 是库，index\ 是全文索引， logs\ 是日志。默认与程序放在一起；Microsoft Store 版因为商店的安装目录对应用只读， 默认落在 %APPDATA%\PMDir，设置页会说明这一次降级的原因。想改位置就在设置页里改。

卸载之后还剩什么？想彻底清干净怎么办？

Microsoft Store 版：商店卸载不会替应用删数据，它会留下两处，请手工删除： 

%APPDATA%\PMDir          库（data\meta.sqlite）、全文索引、日志
%USERPROFILE%\.pmdir     每本库各自的启动前备份，按库分目录

便携版：删掉整个程序目录。安装版：卸载程序会问你是否保留备份，并清掉 ~\.pmdir 下的备份树；数据目录若被你指到过别处，那一处要你自己删。 卸载从不删除你项目里的原始文件。

列表里的「索引 N%」是什么？为什么一直不满？

那个百分比说的是有多少文件已经抽过正文，不是索引层的健康状态。不满 100% 通常有两种情况： 还有文件没抽完（重启应用会继续抽），或者有些文件本来就没有可抽取的正文（比如压缩包、扫描版图片、 没开自动抽取的类型）——这些不算故障。

如果那一格显示的是「索引 —」，说明索引层这次没能打开。这种情况下请打开 「设置 → 重建索引」，点开始重建；多数损坏在启动时会自动恢复（坏掉的索引目录会先改名留档 再重建），留档的那份占的盘要你自行清理。

为什么有的压缩包能读、有的要装 7-Zip？

  • 读取与解压 zip / 7z 用的是程序内置的能力，不需要另外安装软件；
  • 压缩成 7z 需要你的电脑上装有 7-Zip。没装时，这一项根本不会出现在菜单里（不是点了报错）；
  • .rar 目前不处理，所以不会给 rar 包画解压入口。

解压时弹出来问密码，是出问题了吗？

不是。带密码的压缩包读不出里面的清单时，程序会先问一次密码来定落点；取消输入就等于放弃这一单。 解压撞上同名文件时也会问一次怎么处理，答案不会被记住——下一次撞上还是会问。

老的 Word / Excel / PPT（.doc / .xls / .ppt）能搜到内容吗？

可以。这几个 97-2003 格式由程序自带的引擎读取，不要求你装 Office。

启动时提示库文件损坏怎么办？

程序会尝试用最近一次备份（在 ~\.pmdir 下，按库分目录）自动恢复。
